# Tabi Unplugged

GitHub Pages launch build for Tabi Unplugged.

## Repository structure
- `index.html` — public app
- `assets/audio/` — 120 song audio files
- `assets/covers/` — official song artwork
- `assets/images/` — additional app artwork
- `track-manifest.json` — build reference for the 120-song library

## GitHub Pages
Publish from the repository root on the `main` branch.
